# Projects
Different ideas on the daily

## branch/

**BRANCH** — a music-driven generative lightning and vascular growth system.
Thin luminous structures grow across black in real time; the physics is driven
by live analysis of whatever is playing.

Live: https://daxjdavis526.github.io/Projects/branch/

Open it in Safari on an iPhone and use Share → Add to Home Screen to install it
as a full-screen app. See [branch/README.md](branch/README.md) for the controls
and how it works.

## helios/

**HELIOS** — a first-person spaceship flight sandbox through the real solar
system. Cockpit view, warp speeds up to 1000× light, planet autopilot, a dive
through Saturn's rings, and the occasional dogfight. Desktop only (keyboard +
mouse).

Live: https://daxjdavis526.github.io/Projects/helios/

See [helios/README.md](helios/README.md) for the controls.

## scripture-universe/

**SCRIPTURE UNIVERSE** — the Latter-day Saint standard works drawn as one
luminous graph: 39,149 documented cross-references between the Old Testament,
New Testament, Book of Mormon, Doctrine & Covenants, and Pearl of Great
Price, zoomable from the whole canon to a single pair of verses compared word
by word. Every line is typed, confidence-rated, and traceable to its source.
Best on desktop (WebGL2).

Live: https://daxjdavis526.github.io/Projects/scripture-universe/

See [scripture-universe/README.md](scripture-universe/README.md) for the
controls and where the data comes from.
